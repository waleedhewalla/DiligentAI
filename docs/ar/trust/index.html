الثقة وإقامة البيانات

ضوابط الأمان

  • بيانات كل عميل معزولة بأمان على مستوى الصف في قاعدة البيانات
  • تشفير أثناء التخزين (AES-256) وأثناء النقل (TLS)
  • دخول موحد للمؤسسات (SAML / OIDC) ومفاتيح مرور وتحقق بخطوتين
  • سجل تدقيق لعمليات الدخول والتصدير والوصول للمنتجات لمدة عامين
  • صلاحية قراءة فقط لأنظمة أرض المصنع افتراضياً
  • لا تُستخدم بياناتك أبداً لتدريب نماذج مشتركة
