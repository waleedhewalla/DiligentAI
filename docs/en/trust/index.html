Trust & data residency

Security controls

  • Each customer's data isolated with database row-level security
  • Encryption at rest (AES-256) and in transit (TLS)
  • Enterprise single sign-on (SAML / OIDC), passkeys and two-step verification
  • Audit log of logins, exports and product access, kept for 2 years
  • Read-only access to shop-floor systems by default
  • Your data is never used to train shared models
